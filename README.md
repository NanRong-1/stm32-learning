# stm32-learning
学习计划
三、阶段一（第1-4周）：C 语言强化 + 单片机入门

### 学习目标

* 把 C 语言从"能看懂"练到"能独立写"，覆盖嵌入式笔试最常考的部分
* 完成 STM32 开发环境搭建，掌握 GPIO、按键、外部中断、串口，建立"程序如何跑在芯片上"的完整认知

### 学习内容

**第1周：C 语言核心（上）**

* 指针与内存：指针运算、指针与数组、二级指针、野指针
* 数据表示：补码、有符号/无符号、大小端
* 位运算：置位/清零/翻转/判断（嵌入式笔试必考）
* 关键字深挖：static、const、volatile、extern（volatile 在嵌入式的意义必考）

**第2周：C 语言核心（下）+ 环境搭建**

* 结构体/联合体/枚举、内存对齐（面试常考）
* 函数指针与回调、宏函数与 do{}while(0) 技巧
* 内存布局：栈/堆/全局区/常量区，.text/.data/.bss 段
* 安装 Keil MDK 或 STM32CubeIDE，烧录第一支程序（点灯）

**第3周：STM32 入门（上）**

* 芯片认知：F103 最小系统（电源、晶振、复位、BOOT）——为阶段三画板埋伏笔
* GPIO：推挽/开漏、上拉/下拉，点灯、蜂鸣器、继电器（衔接你的电气经验）
* 按键输入与软件消抖

**第4周：STM32 入门（下）**

* 中断系统与 NVIC 优先级、外部中断 EXTI
* USART 串口：printf 重定向、自定义收发协议帧
* 启动流程：从上电到 main()（启动文件、中断向量表、堆栈初始化——面试常问）

### 达成检验标准（全部通过才算过关）

1. 独立完成**小作品1**：8 只 LED 流水灯 + 按键切换模式 + 串口命令控制，不看教程现场写并讲解每行代码
2. C 语言自测 50 题（指针/位操作/关键字/内存），正确率 ≥ 80%
3. 口头讲清 3 个问题：volatile 为什么必须用；代码从上电到 main() 经历了什么；推挽和开漏的区别及各自用法
4. 建立 Git 仓库，所有代码入库（这就是你以后的"作品集"）

## 四、阶段二（第5-10周）：STM32 外设系统学习

### 学习目标

* 系统掌握嵌入式硬件工程师面试必问的全部外设，达到"不看教程、独立配置"的水平
* 完成一个覆盖 5 种以上外设的综合项目，作为简历主力项目

### 学习内容

**第5周：定时器**

* 基本定时器定时中断、SysTick
* PWM 输出：呼吸灯、舵机、电机调速（结合电机知识讲 MOS 驱动）

**第6周：串行通信**

* I2C 协议：OLED 屏、EEPROM（AT24C02），软件 I2C 与硬件 I2C 的区别
* SPI 协议：SPI Flash（W25Q64），片选/四种模式

**第7周：ADC 与 DMA**

* ADC 采集：电压、电位器、NTC 测温
* DMA：串口 DMA 收发、ADC 多通道 DMA，理解"为什么不占 CPU"

**第8周：工程化与可靠性**

* 看门狗（独立/窗口）、低功耗模式（睡眠/停止/待机）
* 模块化编程：工程分层（驱动/逻辑/应用）、头文件组织
* 面试高频：中断里为什么不能延时、printf 为什么不能在中断里用

**第9-10周：综合项目2（简历主力）**

* 三选一：① 多路电压电流采集终端（分压/分流采样 + OLED 显示 + 串口上报）；② 智能环境监测站；③ 两轮小车
* **推荐选①**——直接呼应"电气背景+硬件岗位"，面试差异化最强

### 达成检验标准

1. 随机抽一个外设（如 I2C），30 分钟内不查教程完成从工程建立到功能跑通
2. 综合项目有实物运行视频 + 项目文档（功能框图、数据流图、遇到的问题及解决过程）
3. 能画出 I2C/SPI 完整时序图并解释起始/停止/应答
4. 能回答：DMA 是什么、为什么快；12 位 ADC 分辨率对应多少电压；看门狗解决什么问题

## 五、阶段三（第11-14周）：硬件设计能力补强（你的优势放大区）

### 学习目标

* 掌握"原理图 → PCB → 焊接 → 调试"的完整硬件开发流程
* 用电气基础打差异化：电源、隔离、电机驱动电路

### 学习内容

**第11周：原理图设计（立创 EDA，免费）**

* STM32 最小系统逐个讲透：LDO 电源（3.3V）、8MHz 晶振、复位电路、BOOT 配置、每个 VDD 的去耦电容为什么必须加
* 常用电路：LED 驱动、按键、上拉电阻取值、三极管/MOS 开关电路、光耦隔离（衔接 PLC 经验）

**第12周：PCB 设计**

* 元件封装、布局原则（先大后小、信号流向、电源分区）
* 布线规则：线宽与电流、过孔、地平面、晶振包地
* DRC 检查 → 打样下单（嘉立创，约一周到货）

**第13周：焊接与仪器调试**

* 焊接练习：直插 + 0805/0603 贴片（先在废板上练手）
* 仪器：万用表测通断电压、示波器看 PWM 与串口波形、逻辑分析仪抓 I2C/SPI 时序
* 等板期间：电源专题——220V→5V→3.3V 完整链路、DC-DC 与 LDO 选型（面试常问）

**第14周：板级调试 + 电机驱动专题**

* 自己的板子烧程序、排除焊接故障（虚焊/短路排查流程）
* 直流电机驱动：H 桥、MOS 管选型、续流二极管、PWM 调速（用上你的电机学底子）
* 强弱电接口：继电器驱动电路、隔离设计——PLC 经验的硬件版翻译

### 达成检验标准

1. **项目3 实物**：自己画的 2 层板，焊接完成后下载程序、外设功能全部跑通
2. 示波器实测 3 张波形图（PWM、串口 TX、上电复位），能逐张讲解
3. 面试题自测：去耦电容作用与容值选择、上拉电阻如何取值、LDO 和 DC-DC 的区别与纹波、MOS 和三极管驱动的区别——全部能脱稿讲
4. 完整经历一次"画板-打样-焊接-调试-排错"闭环，写成复盘笔记（面试讲故事的最好素材）

## 六、阶段四（第15-16周）：RTOS + 求职冲刺

### 学习目标

* 掌握 FreeRTOS 核心概念（初级岗位高频要求）
* 完成简历定稿与面试准备，进入"随时可面"状态

### 学习内容

**第15周：FreeRTOS**

* 任务与调度（抢占/时间片）、任务优先级设计
* 队列、信号量、互斥量、事件组——每个都用"生产者-消费者"例子练一遍
* 实操：把项目2改造成 FreeRTOS 版（采集任务+显示任务+通信任务，用队列传数据）

**第16周：求职冲刺**

* 简历定稿：突出 3 个项目 + 电气/PLC 差异化背景，每个项目按"背景-方案-难点-结果"写
* 面试题库过 3 遍：C 语言笔试 50 题、STM32 外设 30 题、硬件电路 30 题、数模电基础 20 题
* 自我介绍准备 1 分钟/3 分钟两版，每个项目准备 5 分钟讲述话术
* 模拟面试 2 轮（可由群内面试模拟官组织）

### 达成检验标准

1. FreeRTOS 版项目运行稳定，能讲清"什么时候必须用 RTOS、队列和全局变量的区别、优先级反转"
2. 笔试模拟（C + 数模电）正确率 ≥ 75%
3. 2 轮全真模拟面试完成，自我介绍和项目讲述不看稿
4. 简历定稿并开始高频投递，进入"每天投递+复盘"循环
